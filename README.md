# Juultje Zeeland

Website voor Juultje Zeeland: vakantiehuisje en appartement in Wissenkerke, Noord-Beveland.

- Statische site (één `index.html`), gehost op GitHub Pages
- Boekingen via de Smoobu Booking Engine (iframe in de sectie `#boeken`)
- Foto's komen in `assets/fotos/`

## Nog te doen
- Foto's toevoegen en de placeholders (`.foto` blokken) vervangen door `<img>`
- Reviewscores en reviews invullen (placeholders tussen [haken])
- Mailadres invullen en contactformulier koppelen (bijvoorbeeld Formspree)
- Duitse en Engelse versie (`/de/` en `/en/`, Smoobu iframe url met `/de/` en `/en/`)
- Pagina's voor huisregels, algemene voorwaarden, annuleringsvoorwaarden en privacyverklaring
- Eigen domein juultjezeeland.nl koppelen (CNAME)
